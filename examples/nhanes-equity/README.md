# NHANES Health Equity classroom data

This folder contains the cached, offline-first classroom data used by the
assignment starters:

- `data/nhanes_equity_v6.csv` for Quarto, R, and Python exercises;
- `data/nhanes_equity_v6.rds` for course examples that explicitly request RDS.

The files are prepared from CDC/NCHS NHANES public-use data. They support
descriptive classroom learning and must not be treated as a causal or
population-representative analysis without the appropriate survey design.
Do not upload row-level records to external AI tools.
