# Publishing Checklist

## Selected Route: Private Preview

I will use a private preview to review `report.html`. Public publishing is not planned because the repository and any applicable group privacy checks have not yet been fully verified.

## Preview Procedure

1. Render the report from the repository root:
   `quarto render assignments/assignment09-reporting/submission/report.qmd`
2. Download the generated `report.html` and open it locally in a browser.
3. Check that the text, tables, figures, and citations display correctly.
4. Provide course staff with access to the private repository when needed.

## Before Submission

- [ ] Report renders successfully from source.
- [ ] Citations resolve and numerical claims match the generated results.
- [ ] Tables and figures are generated by code.
- [ ] Staged files contain no raw row-level data, credentials, `.RData` workspaces, or unrelated generated files.
- [ ] `report.qmd` and the required `report.html` are included in the commit.
- [ ] Course staff can access the private repository when needed.
- [ ] Canvas submission includes the repository link, report path, and latest commit hash.
